tabs-permission probe — dev only, never shipped

With tabs removed from the manifest, what can the service worker still see of a tab? Opens a permitted listing page, navigates it to another listing and then to an unpermitted host, and opens the extension's own search page — reading tabs.get and recording every tabs.onUpdated delivery, plus every presence-port connect/disconnect (the replacement guard's signal).

Open with ?auto=1 (the worker does this when launched via npm run probe:perm) or press Run. Re-run the whole thing with PROBE_WITH_TABS=1 to get the control: the same measurements with the permission granted. Artifacts are POSTed to the capture server on 127.0.0.1:8787 if it is running — use OUT_DIR=probe-out so they land outside the fixture corpus.
